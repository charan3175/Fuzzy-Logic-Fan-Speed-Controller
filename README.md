# 📖 About The Project

Traditional fan controllers operate using fixed thresholds, which often result in abrupt changes in fan speed.

This project demonstrates an **AI-based Fuzzy Logic Controller** that intelligently determines the most suitable fan speed by analyzing:

- 🌡️ Room Temperature
- 👥 Room Occupancy

Using **Mamdani Fuzzy Inference**, the controller provides smooth and human-like decisions instead of rigid ON/OFF control.
